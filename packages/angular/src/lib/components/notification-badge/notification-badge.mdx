## Overview

Attention indicator anchored to whatever it wraps — an icon button, a nav item, an
avatar. Three shapes: `dot` (something is new), `count` (how many), and `pill`
(counts that need room); `maxCount` caps the display ("99+"). Position it on any
corner of the wrapped content.

Radius and offset resolve from the `notificationBadge` theme options; the badge
wears the active `variant` color.

## Accessibility

- The visual badge is hidden from assistive tech; a visually-hidden text announcement carries the meaning ("3 notifications").
- Provide `ariaLabel` context when the wrapped control's purpose isn't obvious from its own name.

## Don't

- Convey urgency by color alone — the count/dot shape carries the signal
