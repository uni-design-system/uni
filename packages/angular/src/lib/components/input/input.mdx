## Overview

Single-line text field with the shared input chrome (themed color, border, typeface,
focus ring, error state). It implements `FormValueControl<string>`: bind a Signal
Forms field with `[field]`, or drive `[(value)]` directly. Errors style the field
only after the user has interacted (touched or dirty), and `required` syncs from
`required()` validators automatically.

Project adornments with the `pre-input` / `post-input` slots. For multi-line text
use Textarea; for search semantics use Search Input.

## Accessibility

- `label` is required and becomes the accessible name (`aria-label`).
- `aria-invalid` reflects the error state once the field was touched or is dirty.
- `aria-required` mirrors the `required` state synced from validators.
- Link external error text with `ariaDescribedBy`.
