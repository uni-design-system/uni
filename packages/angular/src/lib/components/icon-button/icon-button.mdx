## Overview

A square, icon-only button for toolbars, bars, and tight layouts. Renders a real
`<button>` around a symbol or icon, with ghost as the default variant so it sits
quietly on any surface. Because there is no visible text, the accessible name comes
from projected (visually hidden) text or `ariaLabel`.

## Accessibility

- Icon-only buttons need a name: project text (rendered visually hidden) or set `ariaLabel`.
- The icon/symbol itself is decorative (`aria-hidden`).
