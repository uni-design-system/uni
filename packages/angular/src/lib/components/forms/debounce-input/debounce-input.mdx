## Overview

A themed text input that emits its `change` output only after the user pauses typing
(400&nbsp;ms by default) and only when the value actually changed — a signal-based
debounce with no rxjs involved. The live value is exposed as the `value` signal, and
`clear()` empties the field immediately (cancelling any pending emit).

It wears the shared input chrome (color, border, typeface, focus ring) via the input
box, and offers `pre-input` / `post-input` attribute slots for adornments plus ARIA
passthrough inputs (`role`, `ariaExpanded`, `ariaControls`, `ariaActivedescendant`)
so composite widgets can annotate the real input element.

Used by the [Search Input](?path=/docs/components-forms-search-input--search-input), which
projects its magnifier and clear button through the slots and drives the combobox
ARIA through the passthroughs.

## Accessibility

- Set `label` — it becomes the accessible name (`aria-label`) of the inner input.
- The ARIA passthrough inputs (`role`, `ariaExpanded`, `ariaControls`,
  `ariaActivedescendant`) exist so composite widgets annotate the real input element —
  see Search Input's combobox.
