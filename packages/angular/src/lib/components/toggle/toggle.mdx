## Overview

A switch-style control for turning an option on or off with immediate effect —
prefer it over a checkbox when the change applies instantly (settings, feature
switches) rather than as part of a submitted form. It implements
`FormCheckboxControl`, so it binds with the Signal Forms `[field]` directive or a
direct `[(checked)]` model.

Track, knob, and size resolve from the `toggle` theme options; the checked state
wears the active `variant` color.

## Accessibility

- Semantic `<input type="checkbox">` with `role="switch"`, properly associated with its label.
- Space toggles; focus indicators are provided for keyboard navigation.
- Screen readers announce the label and on/off state.

## Do

- Use for instant on/off effects (settings, feature switches)

## Don't

- Use in submitted forms where nothing happens until save — that is a checkbox
