## Overview

Single choice among a small set of visible options. The component renders the whole
group from an `options` array (`{ label, value, disabled? }`), implements
`FormValueControl<string>` for Signal Forms, and defaults each group to a unique
`name` so multiple groups on a page never collide.

Ring, fill, and size resolve from the `radio` theme options; the selected dot wears
the active `variant` color.

## Accessibility

- `role="radiogroup"` labelled by the group label via `aria-labelledby`.
- Native radio inputs: arrow keys move selection within the group, Tab moves out.
- `aria-invalid` reflects the error state once the group was touched or is dirty.

## Do

- Use for 2–5 mutually exclusive options that should all be visible

## Don't

- Use for long option lists — that is a select
