## Overview

The Input Box is the themed shell shared by all text-like form controls
([Input](?path=/docs/components-forms-input--input),
[Select](?path=/docs/components-forms-select--select), Multi Select Dropdown). It projects any
native `input` or `select` element, strips the platform's default styling, and applies the
`input` component theme options: colors, border, radius, focus outline, and the error and
disabled states.

Use it directly when composing a custom form control that should match the design system's
input styling.

## Sizing

The `<uni-input-box>` host is `display: contents` — it is layout-transparent, so the
real box is the flex row inside it. That means a width, a `grow`, or a layout
attribute set on the element itself is dropped.

Size it with `width`, `fullWidth`, `grow` and `minWidth`, which reach the inner
box; there is no need to wrap it in a `<div>`. `uni-input`, `uni-textarea` and
`uni-select` forward the same four.

```html
<uni-input-box fullWidth>…</uni-input-box>
<uni-input label="City" [grow]="1" />
```

## Theme options

<ThemeOptions componentName="input" />

Beyond the default focus outline (`focusOutline`/`focusOutlineOffset`), a theme
can restyle the whole focused box with the optional trio `focusBorder`
(a border primitive), `focusShadow` (e.g. a soft `0 0 0 3px` ring) and
`focusColor` (background) — the Wellsourced showcase theme uses all three for
its ochre focus ring. They apply while any projected control has focus and
yield to the error state, so a flagged field stays visibly flagged.
