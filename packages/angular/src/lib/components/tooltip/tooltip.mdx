## Overview

A tooltip is a brief, informative message that appears when a user interacts with an element.
If using a tooltip within a body of text, set the `inlineText` option to `true`.

Wrapping an interactive control (a button, a link) is supported: activating
the control hides the bubble and keeps it hidden until the pointer leaves and
returns, so a label that changes with the control's state ("Expand" →
"Collapse") never blinks back mid-interaction. Tapping a non-interactive
tooltip (inline text) still toggles the bubble.

## Accessibility

- `role="tooltip"` linked to the trigger via `aria-describedby` (wired once — the bubble is always in the DOM).
- Shows on keyboard focus, hides on blur and Escape; stays open while hovered (WCAG 1.4.13).
- Non-focusable triggers get `tabindex="0"` so keyboard users can reach the tooltip.
