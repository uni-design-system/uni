## Overview

Generic search field wearing the shared input chrome: a decorative leading magnifier,
a clear button while there's a query, and Enter to submit (`searchSubmit`). `searchChange` emits
debounced as the user types — use it to refresh results or the `suggestions` input.

With `suggestions`, the field becomes an ARIA combobox: entries render in a listbox
under the field, ArrowUp/Down move the highlight, Enter selects (emitting both
`suggestionSelected` and `searchSubmit`), and Escape closes the list first, then clears the
query. The suggestion list's surface, elevation and radius resolve from the theme's
`searchInput` options, alongside the search/clear symbols.

## Suggestion popup

The list renders in the browser's top layer, anchored to the field, so it is
never clipped by a scrolling or `overflow: hidden` ancestor — put this control
inside a card, a table cell or a dialog and the list still escapes the box. The
browser tracks the field itself; the list follows on scroll and resize, and
flips above the field near the bottom of the viewport.

Browsers without CSS anchor positioning keep the older in-flow popup, which
does clip inside such ancestors.

## Accessibility

- The field is an ARIA combobox: `aria-expanded`, `aria-controls`, and `aria-activedescendant` track the suggestion listbox.
- ArrowUp/ArrowDown move the active option, Enter selects, Escape closes the list first and clears the query second.
- The magnifier is decorative; the clear button has an accessible name ("Clear search").
