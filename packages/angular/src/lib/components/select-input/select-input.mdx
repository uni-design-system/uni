## Overview

Single choice from a list, on a native `<select>` — platform pickers on mobile,
platform keyboard behavior everywhere. Options are typed generically
(`options: T[]` with `optionLabel`/`optionValue` accessors), and the component
implements `FormValueControl` for the Signal Forms `[field]` directive. Errors
style the field only after interaction, matching Input.

For choosing several, use Multi Select; for type-to-filter over large sets, use
Search Input's type-ahead.
