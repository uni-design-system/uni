## Overview

Box is the base Layout component. It is highly configurable.
Each layout component extends the Box component while providing presets to support their application.

## Usage

<StoryUsage of={Stories.Primary} />


## Examples

### Basic Box with Styling

```html
<div box-layout color="primary-container" borderRadius="lg" padding="md">Content goes here</div>
```

### Flex Container Box

```html
<div box-layout display="flex" flexDirection="row" alignItems="center" justifyContent="space-between" gap="md">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
```

### Box with Border and Shadow

```html
<div box-layout border="outline" borderRadius="md" elevation="md" padding="lg">
  Content with border and shadow
</div>
```

### Responsive Box

```html
<div box-layout width="100%" maxWidth="800px" padding="md"> Responsive content </div>
```
