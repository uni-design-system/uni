## Overview

The Expand Toggle is a chevron icon button that controls collapsed/expanded state. It pairs
with the [Expand](?path=/docs/components-expand--docs) component: bind the toggle's
`collapsed` model to the Expand's `collapsed` input to build collapsible sections.

The icon rotates 180° between states and shows an "Expand"/"Collapse" tooltip.

## Labelled

Set `label` (and optionally `sublabel`) and the toggle becomes a full-width row:
chevron, label, muted qualifier. Most disclosures need to name the section they
control, and hand-building that row is what consumers were otherwise forced to
do. The labelled shape is a single button whose accessible name is the label,
so screen readers announce "Dimensions & Materials, collapsed" rather than a
bare "Expand" next to unrelated text. The tooltip is dropped here — the label
already says what the region is.

Only the chevron rotates, not the row, so the label stays upright.

## Accessibility

- `aria-expanded` is set for you from `collapsed`.
- Pass `ariaControls` the Expand's `regionId` so the trigger points at its
  region: `<uni-expand #region /><uni-expand-toggle [ariaControls]="region.regionId" />`.
- Rotation is motion-safe — it does not animate under `prefers-reduced-motion`.
