## Overview

Icons are adaptive svg images. Instead of defining a size or color attributes, Icons
will grow to the space allotted to them and use the current color of its parent element.

However, it is possible to statically set the icon color.

## Accessibility

- Icons are decorative (`aria-hidden`) — the parent control carries the accessible name.
- Icons come from the theme's `icons` map (masked with `currentColor`); unknown names render nothing.
