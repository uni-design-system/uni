## Overview

Binary choice control for forms: check to opt in, submit to apply. It implements
`FormCheckboxControl` for the Signal Forms `[formField]` directive (or bind
`[(checked)]` directly), exposes `aria-invalid` once touched, and supports an
`indeterminate` model for "select all" parents — cleared automatically on the next
user interaction, matching native behavior.

The box color, check stroke (the variant's paired on-color), and size resolve from
the `checkbox` theme options.

## Accessibility

- Semantic `<input type="checkbox">` + `<label>`; Space toggles.
- `aria-invalid` reflects the error state once the field was touched or is dirty.
- The indeterminate visual state is carried by the native `indeterminate` property, announced as "mixed".

## Do

- Use for choices that apply when the form is submitted

## Don't

- Use for instant on/off effects — that is a toggle
