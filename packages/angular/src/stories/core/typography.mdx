## Overview

Type in Uni is a single numeric scale on the theme — `theme.typography` — keyed by
role (`display-large`, `body-1-long`, `caption`, …). CSS-ready typefaces are
**derived** from that scale on read via `toTypefaces()`, never stored twice, and
every consumer resolves through the same map:

- The [`uni-text` attribute](?path=/docs/components-primitives-text--text) applies a
  typeface to any element: `<h1 uni-text="display-small">`.
- Components reference typefaces **by token name** in their theme options
  (`appBar: { typeface: 'title-large' }`), so re-theming type is a token swap,
  not a stylesheet edit.
- `ThemeService.typeface(role)` returns the resolved definition for custom
  Emotion styles.

Themes may also register typefaces beyond the canonical roles — product extras
like `stat`, `tag`, or `input` — and they appear in the manifest below under
**Component**.
