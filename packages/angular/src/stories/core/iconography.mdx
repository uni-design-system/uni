## Overview

Icons in Uni are **theme primitives**, not inlined SVG. Each icon is an SVG data
URI stored on the theme's `icons` record and rendered by
[`uni-icon`](?path=/docs/components-icon--overview) as a CSS **mask over
`currentColor`** — so every icon recolors with the theme, a color token, or its
container's text color automatically, and no third-party icon font or SVG markup
ever enters your templates.

- The built-in set, `BaseIcons`, is Material Symbols Outlined at weight 300,
  normalized to a single `0 -960 960 960` grid so every glyph shares one optical
  weight. It is generated by `pnpm icons:generate` — add icons in that script's
  manifest, never by hand-editing the record.
- `createTheme` merges a theme's own `icons` over `BaseIcons` per name: reusing
  a built-in name **reskins** it, a new name is simply added. Use
  `svgToIconUri()` to bring your own artwork (a brand set, a designer handoff)
  through the same pipeline — it normalizes the SVG and rejects multi-color
  artwork that would not survive masking.
- Components render icons **by token name** (`<uni-icon name="search" />`), so
  a theme swap can restyle the whole icon language without touching call sites.

## Manifest

Every icon registered in the **active theme**, in registration order. Switch the
theme in the toolbar to see overrides and additions; click a tile to copy its
token name.
