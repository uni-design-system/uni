Calendar, Date & Time Input Uni Design System — prototype, not shipped code

Three foundation components — uni-calendar (an inline month grid with single and range selection), uni-date-input (free-typed parsing + a popup calendar), and uni-time-input (a combobox over time slots) — plus uni-date-time-input, a thin composer that seats a date and a time in one field. Values are plain ISO strings (2026-08-20, 15:00), never Date objects. Everything on this page uses the live Uni palette generated from seed #4F46E5.

1 · Scheduling — the first application

Pick a day, then a slot. Dots are availability markers driven by app data; closed days are disabled. The calendar is one tab stop — arrows move by day, PgUp PgDn by month, Enter selects.

2 · The calendar, on its own

Single — mode="single"

Range — mode="range"

First commit sets the start, the second the end; committing an earlier day swaps the ends. Esc cancels a pending range.

Fenced — min/max, weekends off

Arrows skip disabled days; the fence stops the caret, it never wraps.

Theme options — sm + square days

Day shape is one theme option (dayBorderRadius: 'max' | 'xxs') — circle or square, system-wide, no component change.

3 · Date input

Free text, parsed on commit — not a mask. Enter commits and reformats · ↑ ↓ step a committed date · Alt+↓ or the button opens the calendar · Esc reverts.

Try: 2026-12-01 · 8/20 · aug 20 · mar 1 (→ next March) · aug 32 (invalid, stays)

Parsing, in order

2026-08-20ISO — what agents and APIs write
8/20/2026 · 8/20locale numeric — digit order from Intl, not hardcoded
aug 20 · 20 aug 2026month names, from the locale's own list
missing yearresolves to the next occurrence — nobody schedules into the past
aug 32stays in the field, flagged — a field that swallows a typo is worse than one that shows it in red

4 · Time input

A combobox over time options — the list is assistive, not exhaustive: any parseable time commits, unless slots pins the choices. Value is always 24-hour HH:mm; display follows the locale.

Try: 9 · 930 · 3p · 15:00

Typing 5pm is parseable but unavailable — refused with the reason.

5 · Composed — uni-date-time-input

Two components, one field chrome, one value. The time part stays disabled until a date is chosen; its slots come from slotsFor(date); changing the day clears a slot that no longer exists. The combined value emits only when both parts are set.

6 · Keyboard map

Focus inside the calendar grid

KeyBehaviour
← →Previous / next day — crosses month edges, the grid follows
↑ ↓Same weekday, previous / next week
Home EndFirst / last day of the focused week
PgUp PgDnSame day, previous / next month
Shift+PgUp / PgDnSame day, previous / next year
Enter SpaceSelects the focused day (range: start, then end)
EscCancels a pending range; in a popup, closes it

Focus in the date field

KeyBehaviour
EnterParses and commits; reformats to the display format
↑ ↓Steps a committed date ±1 day; on an empty field, ↓ opens the calendar
Alt+↓Opens the calendar, focus moves to the selected day (or today)
EscReverts uncommitted text to the committed value
Tab / blurCommits typed text, then moves on — never traps

Focus in the time field

KeyBehaviour
↓ ↑Opens the list scrolled to the nearest option, then moves through it
EnterCommits the highlighted option, else parses the typed text
EscCloses the list; if already closed, reverts to the committed value
Tab / blurCommits typed text, never traps

One tab stop per widget: the grid uses roving tabindex like tag-input's chips, so Tab crosses the calendar in one press instead of walking 31 days.
