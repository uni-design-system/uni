Combobox Uni Design System — prototype, not shipped code

uni-combobox is the form-bound, closed-set, single-select autocomplete: FormValueControl<T | null> over object Options<T>, type-to-filter, commit-on-select — typing filters, it never selects. Select semantics, not search: a real label, a chevron, no magnifier, nothing submits. Everything on this page uses the live Uni palette generated from seed #4F46E5.

1 · Type-to-filter, commit-on-select

Fifty options with descriptions, filtered locally as you type. Commit by clicking, by arrowing to an option and Enter, by typing an exact label, or by narrowing the filter to a single candidate and pressing Enter. The ✕ appears only while a value is set; Escape never touches the committed value.

Try: type alab then Enter · type Ohio then Tab · ArrowDown on a committed value.

2 · Disabled options

Option.disabled renders the option visibly and announces it, but arrows skip it and clicks don't commit — the shared ListboxNavigation grows a disabled hook for this.

3 · Async options (filterLocally=false)

The open-set escape hatch: options render verbatim and the app narrows them from the debounced query output — byte-for-byte the search-input contract. This demo fakes a 300 ms server.

Type two letters and pause; the list fills when the "server" answers.

4 · showError() gating

A required field is invalid from birth but shows nothing until touched or dirty — invalid && (touched || dirty), the library-wide rule. Focus it, pick nothing, and leave.

Blur without choosing → error chrome + aria-invalid. Choose a team → it clears.

5 · Keyboard map

KeyBehaviour
printableedits the draft, filters, opens the list
ArrowDown / ArrowUpopens if closed (Down lands on the committed option, Up on the last); moves through enabled options, wrapping
Alt+ArrowDown / Alt+ArrowUpopens without activating / closes keeping the draft
Home / Endfirst / last enabled option while the list is open
Entercommits the active option, an exact label match, or a uniquely-filtered option; otherwise keeps the list open and announces
Escapecloses the list; then reverts the draft. Never clears the committed value
Tab / blurcommits an active option or exact match, else reverts (rejected); moves on — never traps; marks touched
