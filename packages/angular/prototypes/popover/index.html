Popover, Callout & Tour Uni Design System — prototype, not shipped code

uni-popover upgraded in place — theme-driven chrome, structured regions, a detached anchor, and a tooltip mode — plus a new uni-callout that dims the page and cuts a spotlight around its target, and a thin uni-tour that sequences callouts with action-gated advance. The spotlight is pure CSS anchor positioning: scroll the page with a callout open and watch the hole track its target with zero JS listeners.

1 · Popover — rich mode

Click toggles; native light dismiss (Esc / outside click). Structured popovers add a header, a ✕, and a footer; an autofocus input inside receives focus on open — that's native popover behaviour, inherited for free.

The last button opens a popover anchored to the email field it explains — the trigger keeps the disclosure ARIA, the panel points at the detached anchor.

2 · Popover — tooltip mode

Hover opens after 500 ms; focus opens instantly; the pointer can travel into the panel; Esc dismisses without moving focus (WCAG 1.4.13). ARIA flips to role="tooltip" + aria-describedby.

Tab through the buttons: focus shows each tooltip with no delay.

3 · Callout — spotlight & dim

The scrim is four anchor-positioned strips plus a shadow-painting window — the hole is genuinely empty space, so the target stays clickable while everything else is blocked. Scroll while one is open: the browser tracks the target natively.

Project settings

With the first one open, the name field accepts typing through the hole; Tab cycles the duet loop (panel ⇄ target); Esc dismisses with a reason.

4 · Tour — sequenced callouts, action-gated

Six steps over the card above: a centered welcome, a read-only spotlight, a step that requires typing before Next enables, a step where clicking Save is the advance, a step whose target is missing (skipped with a warning), and a finish.
