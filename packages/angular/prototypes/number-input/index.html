Number input · stepper · range · slider Uni Design System — prototype, not shipped code

uni-number-input replaces <input type="number">, which reports value === '' for any text it can't parse — paste 1.234,56 and the app reads an empty field. Here the field is free text over a canonical decimal string: locale-aware parsing on commit, Intl formatting on blur, scaled-integer stepping (never floats), affix adornments outside the editable text, and steppers with real hit areas. Everything on this page uses the live Uni palette generated from seed #4F46E5.

A money field, a percent field, and a quantity stepper computing one total — the first application. The unit price parses anything a spreadsheet exports; the discount is a display-number percent (15 means 15%, the model is never silently ÷100); the stepper is the same core with no field chrome.

3 · Money & locale parsing

Separators, symbols, and digit sets come from Intl, never hardcoded. The en-US field takes 1,234.56, $1,234.56, and accounting (1,234.56); the de-DE field takes 1.234,56 and puts the € on the locale's side. Unparseable text stays in the field, dashed-underlined, with a rejected event — never silently swallowed.

4 · Precision — scaled integers, never floats

Stepping 0.1 from 0.2 yields exactly 0.3 (a double yields 0.30000000000000004). Rounding is decimal: 1.15 → 1.2 under half-up, because (1.15).toFixed(1) is "1.1". valueAsString keeps digits number can't.

Set 0.2, press ↑ — watch the log for the exact value.

Commit 1.15 → 1.2.

Commit 1.25 → 1.2 (half-up says 1.3) · 1.35 → 1.4 — ties go to the even digit.

Commit 1234567890.1234567 — 17 significant digits — and compare the two models in the log.

5 · Percent & unit suffixes

preset="percent" displays 15 as 15% and the model stays 15 — no silent ÷100. Apps whose model is a fraction opt into valueIsFraction: 0.15 displays as 15% and steps in fraction units. Suffixes are adornments outside the editable text; unitAnnouncement gives the screen reader the long form.

Shows 15% — the model reads 0.15. Check the log.

6 · Expressions & compact entry

allowExpressions accepts spreadsheet arithmetic — 12*3, (2+3)*1.5 — via a tiny shunting-yard evaluator, never eval, and announces the result. Off by default. With compact notation, 1.5k parses to 1500 and large values display as 1.5K.

8 · uni-number-range-input

Two linked fields, one chrome, one { start, end } value — the same field names as UniDateRange. A backwards commit swaps the ends (the calendar's rule); either end alone is a valid filter; the ends fence each other's steppers through minGap.

10 · showError() gating

A required field is invalid from birth but shows nothing until touched or dirty — invalid && (touched || dirty), the library-wide rule. The unparseable-draft underline is independent and immediate: it describes text just typed.

Blur while empty → error chrome + aria-invalid. Commit a value → it clears.
