Tag & Tag Input Uni Design System — prototype, not shipped code

A fresh uni-tag with two style axes — variant (colour role, from the theme) × tone (soft / solid / outline) — plus sizes, a leading slot, and real states. uni-tag-input composes it into a token field; the first application is the email recipient pattern below. Everything on this page uses the live Uni palette generated from seed #4F46E5.

1 · Email recipient input

Type a name or address, or paste a whole list. Enter , ; Space commit · Backspace on an empty field steps back into the chips · Enter or double-click a chip to edit it.

3 · Keyboard map

Focus in the text input

KeyBehaviour
EnterCommits the highlighted suggestion, else the typed text
, ; SpaceCommits the typed text (space only under the email preset)
TabCommits the typed text, then moves on — never traps focus
↓ ↑Moves through suggestions, wrapping
BackspaceOn an empty field: focuses the last chip. It does not delete blind
←With the caret at position 0: focuses the last chip
EscCloses the list; if already closed, clears the typed text
pasteSplits on , ; newline/tab, unwraps Name <a@b.com>, keeps an unterminated tail in the field
blurCommits the typed text, marks touched

Focus on a chip

KeyBehaviour
← →Previous / next chip; right past the last returns to the input
Home EndFirst / last chip
BackspaceRemoves it, focus moves left
DeleteRemoves it, focus moves right
Enter F2Edits — the chip is lifted back into the input as text
EscReturns focus to the input
any characterReturns to the input and types it there

Two deletion keys with opposite focus outcomes is what makes pruning a long recipient list feel right: hold Backspace to eat backwards, Delete to eat forwards, without the caret jumping.
